After you update Codeberg, the app shows these notes once in a **What's new**
window. Each release lists what was added, changed, fixed, or removed.

| When | What you see |
|------|--------------|
| First visit after an update | Notes for up to three releases you have not seen, newest open |
| After you choose **Got it** | Nothing more for that version in this browser |
| First run, or a development build | No window; these docs still list every release |

To update, follow [Update](/docs/getting-started#update) in Getting started,
then reload open Codeberg tabs.
